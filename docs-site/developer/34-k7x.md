# k7x: the text format

`apps/k7-daw-wasm/k7x` is the parser, printer and editor for `.k7x` files, the only format a workspace's
documents are written in: a Strudel-looking syntax that is **parsed and never evaluated**. A call is
a map entry, a chain of calls is a map, and nothing computes. The backend links the crate; the page
reaches it through the browser module, as `@studio/k7-wasm/k7x`. The user-facing syntax is in the user
guide's song file reference.

## Modules

| Part | File | Role |
|---|---|---|
| the reader | `apps/k7-daw-wasm/k7x/src/parse.rs` | `parse_tree(text)` → the root map, every node with its span; a `SyntaxError` with offset, line, column. Duplicate keys are syntax errors. |
| the editor | `apps/k7-daw-wasm/k7x/src/edit/document.rs` | `Document` and its `Scope`: `get_in`, `set_in`, `add_in`, `insert_in`, `delete_in` by key path, rewriting only the edited value's span. |
| the printer | `apps/k7-daw-wasm/k7x/src/edit/print.rs` | `stringify`: the one canonical layout (100 columns) for a file written whole, with `//` header lines and the nodes kept on one line. |
| the outline | `apps/k7-daw-wasm/k7x/src/outline.rs` | The editor's tree as layout cells and one JSON array of keys and scalars (`apps/k7-daw-wasm/k7x/docs/outline.md`). |
| the page's door | `apps/k7-daw-frontend/packages/k7-wasm/src/k7x/` | `K7Document` and `K7Scope` over `k7x.edit`, `parse` over `k7x.data`, `stringify` over `k7x.print`, `parseTree` and `walk` over `k7x.outline`. |

## Where a workspace reads and writes them

`apps/k7-daw-wasm/song-edit/src/workspace_doc.rs` is the door: a file's text (`wsText`), its data with short
forms expanded (`wsData`), an edit by key path (`wsEdit`), or a whole file from data (`wsWriteData`).
A writer takes a `K7Scope` and edits the document in place, so a knob drag stays a one-line diff and
every comment survives. `apps/k7-daw-wasm/song/docs/k7xFiles.md` holds the rules.

**Short forms** (`apps/k7-daw-wasm/song-edit/src/sugar.rs`): `notes("c4 e4")` or
`notes(seq("…").step(0.5).v(0.8))` in a sequence, and `runs([[a, b, c]])` in a graph. `sugar_for(path)`
returns the expansion for a path's kind. On write, a short form whose expansion is unchanged stays
as written; one whose expansion changed is replaced by its full data, or a stale short form would
undo the edit.

What stays YAML is no workspace document: `env.yaml`,
`commands.yaml` and `latest.yml`. The machine's `preferences.k7x` is k7x too, but a machine file and not a workspace one. A save of a `.yaml` path through
the file service is refused.

## Validation and the editor

`validateFile` reads a `.k7x` path with the kind's reader, in Rust; a syntax error is one finding with its
line and column, and a reader's finding is placed on the text by its key path
(`apps/k7-daw-wasm/song/src/files/validate.rs`). The CodeMirror language,
cursor model and completions are in `apps/k7-daw-frontend/packages/ui-editor/src/k7x/`.
