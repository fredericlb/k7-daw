# records

Two beats for the turntables demo, sixteen bars each: `house-124.mp3` and `breaks-128.mp3`.

The drums are hits from **Naked Drums** by Wilkinson Audio (© 2016), as ported to SFZ by sfzinstruments
(https://github.com/sfzinstruments/WilkinsonAudio.NakedDrums), licensed under Creative Commons Attribution 4.0
International (https://creativecommons.org/licenses/by/4.0/) — the files in `k7-core/samples/naked_drums`.
Changed from the original: the hits are sequenced into a pattern and mixed with a synthesised bass line.
