# turntables

Copies of the `@k7-core` modules the turntables demo plays — `audio/eq`, `audio/filter` and `audio/delay` (each with
only the engine the demo picks), and `audio/zz_utility/fade`, `gain` and `trim` — with `cold/tempo` beside them in
`_modules/cold/`. Every demo must compile with no library installed (`packages/song/docs/libraryFiles.md`), and a set
made from the `mix` archetype extends these from `@k7-core`.

They are k7-core's code, so biome leaves this folder alone as it leaves `k7-core/`.
