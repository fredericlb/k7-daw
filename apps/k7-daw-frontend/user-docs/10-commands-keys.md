# Keys

Bindings that aren't a plain command, so they have no entry in the command reference.
Everything else is a command and can also be typed into the command bar.

| Key | What |
| --- | --- |
| `Ctrl Shift P` | open the command bar, a card over the window (⌘ Shift P on a Mac, double-tap Shift, or the bar's first button; Esc closes it) |
| `f` | fullscreen the focused pane |
| `hjkl / ←↓↑→` | move the timeline caret (extends the selection in select mode) |
| `?` | this help — Esc closes it |
